# DiplomSite

Многостраничный сайт для дипломной работы.

## Технологии
- Node.js + Express
- SQLite
- HTML/CSS/JavaScript

## Страницы
- `/` — главная
- `/about` — о проекте
- `/portfolio` — портфолио
- `/contacts` — форма обратной связи

## API
- `GET /api/health`
- `GET /api/messages`
- `POST /api/messages` (name, email, message)

## Запуск
```bash
npm install
npm start
```
